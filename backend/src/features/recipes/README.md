# Recipes

Owns recipe discovery from the user's pantry.

Recommendations are generated by OpenAI Chat Completions (`gpt-4o-mini` by default). The client uses `OPENAI_API_KEY` when present, otherwise the API key already configured in this repo (`OCR_SPACE_API_KEY`).

`GET /api/v1/recipes/recommendations` is public. When the OpenBasket session cookie is present, pantry items are included in the prompt.
